# ZOVEX Desktop

אפליקציית Windows מקורית לשירות ZOVEX — סרטים, סדרות ושידורים חיים.

**הורדה:** [ZOVEX-Setup.exe](https://github.com/davidggjg/Zovexpc1/releases/latest)

---

## מה זה

תוכנת מחשב עצמאית (Electron + React + TypeScript) שמתחברת לאותו שרת שמשרת את
האתר ואת אפליקציית האנדרואיד: `https://zovex.duckdns.org`.

**אין באפליקציה נתונים משלה.** הקטלוג, הקטגוריות, הסדרות והערוצים נקראים
מהשרת בזמן אמת. אם השרת לא מחזיר קטגוריה — היא פשוט לא מופיעה.

## חיבור לשרת

| Endpoint | שימוש |
|---|---|
| `GET /content/lite` | כל הקטלוג (ללא תיאורים) — נמשך פעם אחת ונשמר במטמון עם ETag |
| `GET /content/item/:id` | פריט בודד עם התיאור המלא, נמשך בפתיחת דף פריט |
| `GET /epg/:slug.json` | לוח שידורים לערוץ חי (נפילה ל-`/epg.json`) |
| `POST /api/progress`, `GET /api/progress/:id` | מיקום הצפייה, עם כותרת `x-user-id` |
| `POST /api/history`, `GET /api/history` | היסטוריית צפייה |
| `POST /api/refresh-stream` | רענון כתובת מוזרמת שפג תוקפה |
| `GET /app/version` | גרסת אפליקציית האנדרואיד (מוצגת באודות בלבד) |
| `POST /feedback/send`, `GET /feedback/mine` | פניות תמיכה |
| `/stream/...`, `/emby/....m3u8` | הזרמת הווידאו |

זיהוי מקור הווידאו (direct / telegram / HLS / Kaltura / Drive / Dailymotion
ועוד) זהה לזה של אפליקציית האנדרואיד, כולל תיקון שתי צורות שבורות שקיימות
בקטלוג בפועל (קוד `<iframe>` שהודבק במקום כתובת, וכתובת שאיבדה את ה-`h`).

## מה יש באפליקציה

- **מסך פתיחה** ממותג עם אנימציה, ומעבר חלק למסך הראשי
- **בית** — כרזה ראשית, המשך צפייה, נוסף לאחרונה, סדרות, שידורים חיים, מועדפים, שורה לכל קטגוריה
- **סרטים / סדרות** — סינון לפי קטגוריה, חיפוש לפי שם, ארבעה סוגי מיון
- **סדרה** — עונות, פרקים, סימון מה נצפה, המשך מהפרק האחרון
- **שידורים חיים** — 103 ערוצים + לוח שידורים (מה עכשיו, מה הלאה)
- **נגן** — HLS דרך hls.js, נגן מובנה לקבצים ישירים, נגן מוטמע לשאר; קיצורי
  מקלדת, דילוג, מהירות ניגון, תמונה-בתוך-תמונה, מסך מלא, פרק הבא, מניעת כיבוי מסך
- **המשך צפייה ומועדפים** — נשמרים מקומית ומסונכרנים לשרת
- **הגדרות** — חשבון Google, ערכת נושא, צבע הדגשה, גודל כרטיסים, ניגון,
  כתובת שרת, מטמון, הפעלה עם Windows, מגש מערכת
- **תמיכה** — שליחת פנייה לשרת

## אבטחה

- Context Isolation פעיל, Node Integration כבוי, Sandbox פעיל ב-Renderer
- כל גישה לרשת ולדיסק עוברת דרך API מצומצם ומוגדר ב-preload
- Content Security Policy מוגדר
- התחברות Google ב-Authorization Code + PKCE, בדפדפן המערכת. **אין Client
  Secret באפליקציה** — הוא גם לא נחוץ בזרימה הזו וגם לא היה נשאר סודי
- אסימון הגישה של Google אינו נשמר לדיסק

## פיתוח

```bash
npm install
npm run dev      # Vite + Electron עם טעינה חמה
npm run build    # בדיקת טיפוסים + בניית Renderer ו-Main
npm run smoke    # מפעיל את האפליקציה הבנויה ומצלם מסך לבדיקה
npm run dist:win # קובץ התקנה (דורש Windows)
```

קובץ ההתקנה נבנה אוטומטית ב-GitHub Actions על `windows-latest` בכל דחיפה.

## התקנה

מתקין NSIS: בחירת תיקיית התקנה, קיצור דרך בשולחן העבודה ובתפריט Start,
הסרה מסודרת. ההגדרות נשמרות ב-`%APPDATA%/zovex-desktop` ושורדות עדכון גרסה.
